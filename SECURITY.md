# Security policy

## Supported versions

Security fixes are made for the latest release only. Please update to the [newest version](https://github.com/Tjs4002/SerialScope/releases/latest) before reporting.

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Instead, use GitHub's [private vulnerability reporting](https://github.com/Tjs4002/SerialScope/security/advisories/new) for this repository.

Include what you found, how to reproduce it, and what impact you think it has. You'll get a reply as soon as possible, and credit in the release notes if you'd like it.

## Verifying downloads

Every release `.exe` is built from this repository's source by [GitHub Actions](https://github.com/Tjs4002/SerialScope/actions). If you'd rather not run a downloaded binary, build it yourself with `build.bat`.

Features

Everything you reach for.
Nothing you don't.

Built for ESP32 and Arduino work, with full port settings for every other serial device.

Live plotter

Reads the Arduino Serial Plotter format. Zoom, pan, hover values, min/max/average and a clock-time axis.

Error highlighting

ESP-IDF and Arduino-ESP32 logs in colour: errors red, warnings amber, debug dimmed. Add your own rules too.

Auto-reconnect

Flash new firmware or unplug the board, and SerialScope picks it back up the moment the port returns.

No surprise resets

DTR and RTS stay low by default, so your ESP32 keeps running when you connect instead of rebooting.

Search and filter

Find every match with Ctrl F, or show only (or hide) the lines that mention a word.

Hex view

Offsets, raw bytes and printable characters for GPS modules, Modbus devices and other binary protocols.

Send with history

Pick a line ending, recall the last 50 messages with ↑ ↓, and keep favourites one click away.

Logs and CSV

Save session logs automatically, record plotted readings to CSV, and export graphs as PNG images.

Many devices

Open a new window per board with Ctrl N, each on its own port, and snap them side by side.

Plotter

Numbers in.
Graphs out.

Print one reading per line, the same way you would for the Arduino Serial Plotter. SerialScope draws it live and shows any other text in a panel underneath.

sketch.ino
Serial.println(analogRead(A0));               // one line
Serial.printf("%d %d %d\n", x, y, z);         // three lines
Serial.printf("temp:%.1f,hum:%.1f\n", t, h);  // named lines
  • Scroll to zoom time, Ctrl + scroll for values, right-drag to box-zoom
  • Drag back through the last 50,000 readings, then jump to Live
  • Min, max and average for the part you're looking at
  • Record to CSV for Excel, Sheets or Python
Highlighting

Spot the error before it scrolls away.

SerialScope recognises ESP-IDF (E (123) wifi:) and Arduino-ESP32 ([E][main.cpp:42]) log levels, plus words like error, panic and timeout, and colours the whole line.

  • Your own rules by word or regular expression, in any colour
  • Filter to show only, or hide, the lines that match
  • Millisecond timestamps and Pause display without losing data
  • Dark and light themes, right down to the title bar

"Windows protected your PC"? SerialScope isn't code-signed yet, so SmartScreen may warn you the first time. Click More info → Run anyway. Every release is built and tested publicly by GitHub Actions and comes with a SHA256SUMS.txt file so you can check your download.
FAQ

Questions, answered.

It says the port is busy or in use.
Another program has the port open: usually the Arduino IDE's Serial Monitor, an upload in progress, or another SerialScope window. Close it and click Connect again. Only one program can use a COM port at a time, so disconnect before uploading new firmware.
I only see garbage characters.
The baud rate doesn't match your code. Pick the same number you used in Serial.begin(...). ESP32 boot messages use 115200. For non-Arduino devices, also check the port settings (for example 7E1 instead of 8N1).
My board doesn't appear in the port list.
Try a different USB cable (many are charge-only), then install the driver for your board's USB chip. That's usually the CP210x (Silicon Labs) or CH340 (WCH); the chip name is printed on the board next to the USB port.
The plotter says "Waiting for numbers".
Each line must contain only numbers, optionally with names, like 23.5, 1 2 3 or temp:23.5,hum:41. Lines with other text are shown in the text panel but not plotted.
Does SerialScope connect to the internet?
Only to check for updates: at most twice a day it asks GitHub's public API for the latest release version. No data about you or your devices is sent, and you can turn it off in Settings. See the privacy policy.
Does it work on macOS or Linux?
Not yet. SerialScope uses Windows' built-in tools to stay tiny and install-free. A cross-platform version may come later; open an issue if you'd use it.
Is it really free?
Yes. SerialScope is open source under the MIT License: free to use, share and change, for personal or commercial work.
